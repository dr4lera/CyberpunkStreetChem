# Submission information

Use the GitHub repository and the v0.1.0 **solo release ZIP**, not the source-code ZIP. This is an experimental local two-game passthrough: both owned games run on the same PC. It includes the mod files, hashes, install/restore scripts, installation guide, controls, supported versions and credits/license.

The repository and download do not include retail game content, personal saves or credentials. Read the installation and compatibility information before trying it. No Melty submission has been sent; the owner will test and submit the release themselves. A platform-specific manifest should follow Melty's current requirements if requested.
