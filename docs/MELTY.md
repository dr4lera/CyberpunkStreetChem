# Submission information

Use the GitHub repository and the two v0.1.0 game-specific release ZIPs: **StreetChem-Cyberpunk2077-v0.1.0.zip** for Cyberpunk and **StreetChem-ScheduleI-v0.1.0.zip** for Schedule I. Both halves are needed. They contain game-root mod files; the separate combined Solo ZIP offers the automatic install/restore scripts instead. Do not treat checksum files as mod downloads. This is an experimental local two-game passthrough: both owned games run on the same PC. The repository includes installation, controls, supported versions and credits/license.

The repository and download do not include retail game content, personal saves or credentials. Read the installation and compatibility information before trying it. No Melty submission has been sent; the owner will test and submit the release themselves. A platform-specific manifest should follow Melty's current requirements if requested.
